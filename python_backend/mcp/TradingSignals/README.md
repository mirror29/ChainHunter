# TradingSignals MCP 服务

这是一个专门用于加密货币交易信号分析的MCP服务器模块。

## 功能特性

### 🎯 交易信号分析
- **技术指标计算**: RSI、MACD、布林带、移动平均线
- **多时间框架**: 支持1分钟到1日的多个时间维度
- **信号强度评估**: 0-1范围的量化强度评分
- **风险等级评估**: 低、中、高三个风险级别

### 📊 套利机会检测
- **跨交易所价格监控**: 监控主要交易所价格差异
- **套利收益计算**: 自动计算潜在收益率
- **风险评估**: 评估套利交易的风险水平

### 📈 信号历史分析
- **历史表现统计**: 信号成功率和平均收益
- **信号状态跟踪**: 跟踪信号的执行状态
- **性能指标**: 提供详细的交易表现数据

## 工具函数

### analyze_signals()
分析多个交易对的技术指标并生成交易信号

**参数:**
- `symbols`: 交易对符号列表 (默认: ["BTCUSDT", "ETHUSDT", "BNBUSDT"])
- `timeframes`: 时间框架列表 (默认: ["1h", "4h"])

**返回:**
- 完整的信号分析报告，包括买入/卖出/观望信号

### find_arbitrage()
检查跨交易所套利机会

**参数:**
- `symbols`: 要检查的交易对列表

**返回:**
- 套利机会详情，包括价格差异和预期收益

### get_signal_performance()
获取历史交易信号的表现记录

**参数:**
- `symbol`: 交易对符号
- `limit`: 返回记录数量

**返回:**
- 历史信号记录和统计信息

## 技术实现

### 指标计算
- **RSI**: 相对强弱指标，判断超买超卖状态
- **MACD**: 指数平滑移动平均收敛发散，识别趋势变化
- **布林带**: 价格通道，判断价格相对位置
- **移动平均线**: 多周期均线，识别趋势方向

### 信号生成逻辑
1. 计算各项技术指标
2. 根据指标状态评估信号类型
3. 结合成交量确认信号强度
4. 评估市场波动性确定风险等级
5. 设定目标价格和止损位

### 数据模拟
当前版本使用模拟数据进行演示，在实际部署时需要：
- 集成Binance API获取实时价格数据
- 连接多个交易所API进行套利分析
- 建立数据库存储历史信号记录

## 使用示例

```python
# 分析主要交易对的4小时信号
result = analyze_signals(["BTCUSDT", "ETHUSDT"], ["4h"])

# 检查套利机会
arbitrage = find_arbitrage(["BTCUSDT"])

# 获取BTC信号历史
history = get_signal_performance("BTCUSDT", 20)
```
